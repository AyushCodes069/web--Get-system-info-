# 🌐 Get System Info

A sleek web-based tool to display system information directly in your browser. Built for speed, simplicity, and a touch of Ayush-style innovation.

## 🚀 Features

- View system details like:
  - Device type
  - Operating system
  - Browser name and version
  - Screen resolution
  - Online status
- Lightweight and responsive UI
- No backend required — pure HTML, CSS, and JavaScript

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript (Vanilla)
